# Lab 11 · Harness 模拟回放实验室

> [← 返回 L05 课文](/l05/) · 纯浏览器运行（回放，零调用）· 约 15–20 分钟

> 🧪 **模拟回放 · 非实时运行 · 真实轨迹**（GLM-5.3-flash · 2026-11-11 · mini-swe-agent v2.4.6）——轨迹是真的（真模型、真 bash、真花费约 ¥0.1），体验是回放模拟；长输出为标注式剪辑。

一个真 agent 的一辈子长什么样——六圈之内，它在哪里想、在哪里做、谁判它输赢、谁喊它停？这一局的任务：**造一个有 bug 的冒泡排序 + 3 条 assert，修到全绿再交卷**。结局先给你：`Submitted`，6 次调用，测试 3/3——但**过程才是全部教学内容**：圈 3 你会亲眼看到测试变红，圈 4 看错误怎么变成下一圈的上下文，圈 5 看"全绿了却还不交卷"的多虑，圈 6 看交卷暗号怎么被环境"没收"。

**怎么玩（建议路线）**：

1. **第 0 幕从源头开始**：开考之前，先看考场布置——宪法（system 消息）、任务信封、工具方言、预算四件，全部发生在第一次模型调用之前（harness 先于 agent 存在）；
2. 每圈先写预测（"模型这圈会想什么、做什么"）再看「想」——预测-对照是本实验的灵魂；底部控制条全程固定，随时 ◀ ▶ 逐拍推进；
2. 圈 3 的红输出停一停：失败信息在圈 4 的 THOUGHT 里被谁引用了？
4. 圈 6 特殊演出：暗号 → 比对命中 → 观察被没收 → exit 入史——把"终止即消息"演出来；
5. 底部记忆序列全程累积：旧圈暗化、当前圈高亮——"状态就是消息列表"眼看变长。

## 你刚才摸到的机制（对照课文）

| 回放中的现象 | 课文里的名字 |
|---|---|
| 每圈 想→做→观察入史 | ReAct 循环（Reason→Act→Observe） |
| 记忆序列每圈 +2、旧圈暗化 | 状态=纯 list 消息历史（五零件之二） |
| 解析五步"无注册表，固定 bash" | 工具表在系统提示里（文本方言） |
| 仪表"圈 N/8" | 循环壳+步数上限（五零件之三） |
| 圈 3 红 → 圈 4 职责A 引用失败换路 | 错误回喂=失败变信息 |
| 圈 6 暗号被环境比对命中 | 终止即消息；"模糊交给模型，精确留给自己" |
