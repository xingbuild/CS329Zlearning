# Lab 04 · Agent 选型工作台

> [← 返回 L05 课文](/l05/) · 纯浏览器运行，零依赖 · 约 15–20 分钟

L05 是选型层的讲次——没有"机制要跑"，只有**决策要做**。这个实验室把讲义的三组判据各拆成一个可操作的站：**站①** 给你六张真实任务卡，你来定档选底盘，讲义判据当场对答案；**站②** 把 DSPy Optimizer 的心脏（评估回路 + bootstrap）在浏览器里真跑一遍；**站③** 把 Temporal 的事件溯源复刻成"执行 → 崩溃 → 恢复"的重放机。课文说"框架打包的是你已会的机制"——这里验证给你看。

**怎么玩（建议路线）**：

1. 站①先凭直觉定档六张卡，再读"讲义判据"行的出处理由——错的那几张就是你的选型盲区；
2. 站②先「跑一轮评估」看三个候选的差别，连跑三四轮看分数波动（评测噪声），再「Bootstrap 注入」看 few-shot 怎么改写 P2 的命中率；
3. 站③开着持久执行走完"执行→崩溃→恢复"，看事件日志怎么跳过已完成步；再关掉持久执行重演一遍——同一起点，两种命运。

## 你刚才摸到的机制（对照课文）

| 实验室里的现象 | 课文里的名字 |
|---|---|
| 六张卡先问"下一步依赖观察吗"再定档 | Agency 光谱定档（第一幕 · p.14 原表） |
| 重框架全家桶的抽象税账单 | "每一层抽象都是别人的决定"（开场 A 团队 + 第五幕陷阱） |
| 三候选 × 八样本真采样真打分 | 评估回路 = Optimizer 三零件之一（第二幕） |
| bootstrap 把正确轨迹注入示例槽，命中率改写 | BootstrapFewShot：从错误中选新示例（第二幕 · 50 行复刻） |
| 单轮分数与多轮平均的差距 | 评测要样本量——"评测驱动决策"军规（第五幕 p.127） |
| 恢复时事件逐条重放、跳过已成功步 | 事件溯源 + 持久执行（第四幕 · 从零理解持久执行） |
| 关掉持久化恢复 = 全部重来 | 进程内重试的宿命（术语卡：Durable Execution） |

> 说明：站②的"模型"用概率表 + 伯努利采样模拟（教学版）——真实系统这里是 LLM，但**机制同构**（候选生成 → 评估回路 → 搜索策略）；站③的事件流是真实状态机的真实记录。工程保真，教学诚实。

## 零件图 · 选型层的三组零件（费曼检验）

**Optimizer（站②）**：候选生成器（缺 → 只有一发子弹）／评估回路（缺 → 调 prompt 靠玄学）／搜索策略（缺 → 有了分数不知道下一步往哪走）。
**持久执行（站③）**：append-only 事件日志（缺 → 崩溃即失忆）／重放器 execute(workflow, history)（缺 → 有历史不会用）／Timer 事件（缺 → 长等待必须保活进程）。
**选型判据（站①）**：定档一刀"下一步依赖观察吗"（缺 → 拿锤子找钉子）／底盘账单"抽象税 vs 基础设施"（缺 → 被框架牵着走）／时长判据"跨人类时间 → 持久执行"（缺 → 夜里跑的管道裸奔）。

**检验句**：明早有人问你"我们该不该上多 agent 框架"——不看本站，你能复述出先问哪三个问题吗？
