# L11 · 外部资源与视频

> [← 返回 L11 课文](/l11/) · 2026-11-03 逐条验证可达 · 外链随时间可能失效，发现打不开请反馈

这一页是 L11 课文的**外部对照实验室**。先说一句坦诚的话：**agent 数据领域没有成熟交互件，精华全在论文管线图里**——本页以五来源论文群为主（七条全部 200 验证），按来源家族对位。

## 先做这三个动手任务

::: tip 任务 ① · 对照 Mind2Web 与 OpenCUA 的采集协议
读 [Mind2Web](https://arxiv.org/abs/2306.06070) 与 [OpenCUA](https://arxiv.org/abs/2506.23476) 的数据采集节——列出两者在"谁记录/记录什么/有无推理"上的三个差异，然后回答：如果你要造客服 agent 的演示数据，哪个协议更值得抄？
:::

::: tip 任务 ② · 拆一条挖掘管线
读 [AgentTrek](https://arxiv.org/abs/2412.09605) 的方法图——找到它的三步（教程→重放→验证保留），对照课文第二幕：**哪一步在防"分布偏"**？
:::

::: tip 任务 ③ · 估算合成任务的单位成本
读 [SWE-smith](https://arxiv.org/abs/2504.21798) 摘要——用"50K 任务 / 20 人工时"折算每任务成本，对照站①采购台的价格档位：你的折算和账单一致吗？
:::

## 五来源论文群

- [Mind2Web](https://arxiv.org/abs/2306.06070) / [OpenCUA](https://arxiv.org/abs/2506.23476) **（人类演示）**——众包记录 vs 自机录屏+无障碍树+事后推理合成：两种采集协议的对照样本。
- [SWE-rebench](https://arxiv.org/abs/2410.03713) / [AgentTrek](https://arxiv.org/abs/2412.09605) **（网络挖掘）**——issue/PR 全自动转 21K 任务；教程重放 $0.55/条。
- [Synatra](https://arxiv.org/abs/2410.07541) **（合成轨迹）**——离线把间接知识改写成演示，$0.031/条（人工成本 3%）。
- [SWE-smith](https://arxiv.org/abs/2504.21798) / [R2E-Gym](https://arxiv.org/abs/2406.12045) **（合成任务环境）**——注入 bug/回退 commit 自动造可验证任务：任务本身可以是造的。
