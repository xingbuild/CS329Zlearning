# Lab 06 · 记忆系统模拟器

> [← 返回 L07 课文](/l07/) · 纯浏览器运行，零依赖 · 约 12–15 分钟

L07 的一句话定位是**上下文窗口 ≠ 记忆**——这个实验室把这句断言拆成两个可操作的实验：**站①** 是 Generative Agents 三因子检索的真算版（时近 × 重要性 × 相关性三个滑杆随你拨，排序当场重算）；**站②** 是失忆对照剧场（同一对话流、同一 8 槽 FIFO 窗口，`core_memory_write` 开与关，两种命运）。课文复刻检验题问"三因子缺一会得什么病"——这里可以直接拨出病给你看。

**怎么玩（建议路线）**：

1. 站①选"Klaus 有什么爱好"——先看默认权重的排序，再点「纯时近」：28 天前的金标准掉到哪去了？再点「纯相关」看无关的 Klaus 梯子挤进前排；
2. 换"这几天有什么安排"查询，体会时近主导的查询靠什么因子工作；
3. 站②先开着记忆管理播一遍（看写入时机与淘汰的节奏），再关掉重播——最后那道"你还记得我叫什么吗"，两种结局。

## 你刚才摸到的机制（对照课文）

| 实验室里的现象 | 课文里的名字 |
|---|---|
| 纯时近时今天的面包压过 Maria 借钱 | 缺重要性 = 鸡毛蒜皮与人生大事同权（复刻检验题） |
| 纯相关时 28 天前的办展记忆才浮上来 | 缺时近 = "翻十年前旧账当新闻"的反面——老账要用相关性别针别住 |
| 得分条 = 三段颜色的加权和 | 检索三因子：时近 × 重要性 × 相关性（第三幕 · Generative Agents） |
| RAM 第 8 条进来、第 1 条被划掉 | FIFO 淘汰——工作上下文容量有限（MemGPT 分层架构） |
| `core_memory_write` 抢在淘汰前落袋 | 记忆操作是动作空间的新成员（A∪ℒ 第三次应验） |
| 关掉写入后名字随第 1 条蒸发 | 上下文窗口 ≠ 记忆（本讲第一句话） |

> 说明：站①相关性用标签匹配计算（教学版），真实系统是嵌入向量余弦——机制同构（相似度打分）；时近分 1/(1+天/7) 是指数衰减的教学近似。工程保真，教学诚实。

## 零件图 · 最小记忆系统的五零件（费曼检验）

**检索侧（站①）**：时近衰减（缺 → 老账当新闻）／重要性权重（缺 → 大事小事同权）／相关性匹配（缺 → 退化为关键词匹配）。
**管理侧（站②）**：容量有限的 RAM + FIFO 淘汰（缺 → 无限膨胀直到爆窗）／主动写入决策（缺 → 关键信息随淘汰蒸发）／档案存储（缺 → 写了也没地方放）。

**检验句**：不回看组件，你能说出"检索三因子"与"写入两策略"（即时写 vs 闲时整理）各自治的病吗？
