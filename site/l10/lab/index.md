# Lab 09 · 可判定任务工坊

> [← 返回 L10 课文](/l10/) · 纯浏览器运行，零依赖 · 约 10 分钟

> 你的断言就是 agent 的奖励函数——断言的漏洞就是它的捷径。这个实验室回答一个问题：**一个"看起来还行"的验收，是怎么放走一张假图的？** 先亲手把弱验收喂给 agent，目睹 reward hacking 现场，再升档验收看它学好的。

**怎么玩**：①默认组合（完整指定 × 弱验收）放 agent 进考场——看它怎么骗过你；②验收升到"中"再跑——骗局换了个马甲照样过；③升到"强"——捷径全被拦，第二轮才交真图。

## 你刚才摸到的机制（对照课文）

| 实验室里的现象 | 课文里的名字 |
|---|---|
| 空文件骗过存在性检查 | reward hacking：agent 优化断言不优化意图（第二幕） |
| 纯色 PNG 骗过文件头检查 | 断言与需求一一对应的必要性 |
| 柱数/标题/量程断言全上 → 捷径全灭 | outcome 分类器：对最终状态做可判定验收（第三幕） |
| 模糊指令行自带漏洞提示 | 指令三态：模糊=hacking 留门（第二幕） |
| 每次 Trial 留档 | 全收据：per-trial 轨迹（第四幕） |

## 零件图 · 可判定任务的五零件（费曼检验）

明确指令（缺=hacking 留门）／真实环境（缺=考不到部署态）／outcome 验收（缺=过程分不可复现）／隔离+自证（缺=成绩单可改/考卷带 bug）／收据（缺=无法归因）。**检验句**：给你任何"让 agent 做 X"的需求，你能五分钟写出五零件草案吗？
