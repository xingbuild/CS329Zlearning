# Lab 02 · RAG 交互实验室

> [← 返回 L03 课文](/l03/) · 纯浏览器运行，零依赖 · 约 15–20 分钟

把 L03 的整条管道**亲手跑一遍**：五份小文档的语料库，经三种分块策略真实切分，被 BM25 / 向量 / 混合三种检索器真实检索（全部计算在你的浏览器里实时完成），最后组装上下文并判定成败。你会亲眼看到：**关键证据在什么切法下被切断、干扰文档如何挤掉正确答案、证据排第几位会怎样**——课文里“答案错了先查管道”的排查顺序，在这里变成可操作的经验。

**怎么玩（建议路线）**：

1. 用默认配置走完五步（固定 45 字 + BM25 + 问题 B）——大概率以 ❌ 收场；
2. 别急着怪模型：回第 ② 步换“固定 + 重叠”或“按结构”，再走一遍——看召回天花板怎么消失；
3. 在第 ④ 步切换三种检索器，对比命中词与排名的差异；
4. 回第 ① 步关掉干扰文档，看问题 B 的排名怎么变干净；
5. 换问题 A / C，体会精确词、释义、跨文档竞争三种考法。

## 你刚才摸到的机制（对照课文）

| 实验室里的现象 | 课文里的名字 |
|---|---|
| 固定 45 字把"周四09:00平均3人"切断在边界 | 分块定下限（第二幕 · 分块实验室） |
| 证据没进 top-3，判定给幻觉风险 | 召回天花板（第五幕 · 失败动物园·检索侧） |
| 干扰文档含相似词挤掉金标准 | 干扰项（失败动物园·阅读侧） |
| 证据排第 2/3 位时把握下降 | 中间丢失 Lost in the Middle |
| BM25 与向量的命中词不同 | 两代检索器的失效面互补 → RRF 混合（第三幕） |

> 说明：实验室的“向量检索”用字符三元组 TF-IDF 余弦实现（教学版）——真实系统这里是神经嵌入，但**机制同构**（向量空间 + 相似度排序）；“生成”步骤用位置概率模拟 LLM 的 U 形注意力。工程保真，教学诚实。

## 零件图 · 最小 RAG 的五个零件（费曼检验）

1. **分块器**——策略与边界（缺 → 证据被切断，Lab02 第②站红色卡）；
2. **索引**——向量库 / BM25 倒排（缺 → 无从检索）；
3. **检索器 + 融合**——打分排序、RRF（缺 → 干扰项上桌）；
4. **上下文组装**——top-k 进窗与位置（缺 → 中间丢失）；
5. **验证与停止**——答案判定/引用（缺 → 幻觉无门）。

**检验句**：让你从零复刻 Lab02，最先卡住的是哪个零件？
