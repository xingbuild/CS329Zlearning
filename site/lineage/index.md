# 技术谱系 · 全课程的问题演进

> 八讲的全部技术，挂在一条"问题演进"链上：**背景 → 根本问题 → 技术应答 → 代价 → 新问题 → 下一代**。技术不是被更好的技术打败的，是被自己产生的新问题推着走的。点击任一节点进入对应讲次。

<LineageMap />

## 怎么用这张图

1. **先横着读一遍**（不看技术只看"问题"列）——你会发现问题的演进本身就有故事：从"规则写不完"到"大脑不可插拔"到"只会说话"到"不可靠"到"碎片化"……每一代问题都由上一代的代价定义；
2. **再任选一个节点竖着读**：进对应讲次，看那个问题被怎样解决、付出了什么；
3. **对照首页的 [Agent 全景解剖图](/)**——那张管空间（agent 由什么构成），这张管时间（为什么长成这样）。
