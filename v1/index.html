如何使用本课程
  1. 读 —— 每讲按「场景 → 本质 → 机制 → 思考题」四段推进，先见问题，后见方法。
  2. 玩 —— 讲义里的交互组件是课程的一部分：逐步播放、拨动参数、看因果，玩过才算学过。
  3. 答 —— 每讲末尾的思考题先自己答，再展开参考答案；答不上来回上一幕。
  4. 进度本地保存 —— 「标记已学完」记录在本机浏览器，无需注册登录。

这条线贯穿全课程

Agent = 循环（五十年历史） + 通用大脑（LLM）。 全课只做一件事：给概率大脑加确定性边界——结构化输出、校验闸、工具协议、记忆系统、评测与安全， 并在误差复利 pⁿ 的现实里，把工程做可靠。
