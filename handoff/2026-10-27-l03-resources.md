## 1 · 材料清单（19 条，2026-10-27 逐链验证可达；标注"仅存活"者为 JS 应用，抓取只见标题，功能据作者公开描述）

**第一幕 · Retriever–Reader 框架与 RAG 的两副面孔**
1. IBM Technology《What is Retrieval-Augmented Generation (RAG)?》（视频，约 6 分钟）— https://www.youtube.com/watch?v=T-D1OfcDW1M — 参数记忆 vs 即时证据的最清晰入门短片（YouTube 可开自动中文字幕）。
2. Jay Alammar《The Illustrated Retrieval Transformer》（图文，2022）— https://jalammar.github.io/illustrated-retrieval-transformer/ — RETRO：以 GPT-3 约 4% 参数量靠查库匹配其表现；文末综述 REALM / DPR / FiD / RAG。正对课文"术语考古"——论文里的 RAG 是端到端联合训练模型。

**第二幕 · 索引侧：分块、上下文注入、向量物理层**
3. ChunkViz（交互，仅存活）— https://chunkviz.com/ — Greg Kamradt 作品：粘贴文本、选切分器、拨 chunk size / overlap，块边界实时高亮。页内「分块实验室」的外部对照版。
4. Greg Kamradt《The 5 Levels Of Text Splitting For Retrieval》（视频，约 1 小时）— https://www.youtube.com/watch?v=8OJC21T2SL4 — 字符 → 递归 → 文档结构 → 语义 → Agentic 五级切分，正对讲义 p.24 四代策略。
5. Jina AI《Late Chunking in Long-Context Embedding Models》（图文，2024-08）— https://jina.ai/news/late-chunking-in-long-context-embedding-models/ — Late Chunking 概念出处（讲义 p.30–31），含朴素分块 vs 晚分块示意与 BeIR nDCG@10 基准。
6. Microsoft GraphRAG 文档 — https://microsoft.github.io/graphrag/ — LLM 抽实体关系建图、Leiden 聚类、社区摘要；Global / Local / DRIFT 三种搜索（讲义 p.34–35）。
7. TensorFlow Embedding Projector（交互）— https://projector.tensorflow.org/ — PCA / t-SNE / UMAP 投影高维向量，点选任一点看最近邻——"向量检索到底在比什么"的直觉来源。
8. WizMap（交互，仅存活）— https://poloclub.github.io/wizmap/ — Georgia Tech Polo Club，浏览器内探索百万级 embedding 地图。
9. Pinecone《Hierarchical Navigable Small Worlds (HNSW)》（图文）— https://www.pinecone.io/learn/series/faiss/hnsw/ — 跳表 → NSW → 分层图的推导；M / efConstruction / efSearch 参数与召回–速度–内存基准（讲义 p.36–38）。

**第三幕 · 检索侧：三代检索器、漏斗与评估**
10. Elastic《Practical BM25 — Part 2: The BM25 Algorithm and its Variables》（图文，2018）— https://www.elastic.co/blog/practical-bm25-part-2-the-bm25-algorithm-and-its-variables — IDF × 词频饱和（k1）× 长度归一（b），三套索引实证对比（讲义 p.41）。
11. Pinecone《Rerankers and Two-Stage Retrieval》（图文）— https://www.pinecone.io/learn/series/rag/rerankers/ — bi-encoder 粗筛 → cross-encoder 精排漏斗；"4000 万文档 BERT 重排需 50+ 小时 vs 向量检索 <100ms"的量级对比（讲义 p.50）。
12. Pinecone《Evaluation Measures in Information Retrieval》（图文 + 代码）— https://www.pinecone.io/learn/offline-evaluation/ — Recall@K / MRR / MAP / nDCG 逐步手算例（讲义 p.45–46）。
13. MTEB Leaderboard（交互榜单）— https://huggingface.co/spaces/mteb/leaderboard — 嵌入模型按检索等任务排名，选型用。

**第四幕 · Agentic RAG：把检索变成动作**
14. LangChain《RAG From Scratch》（视频系列 18 集 + notebooks）— 播放列表 https://youtube.com/playlist?list=PLfaIDFEXuae2LXbO1_PKyVJiQ23ZztA0x ；代码 https://github.com/langchain-ai/rag-from-scratch （约 9.5k★）— 索引/检索 → 查询改写、路由、RAG-Fusion、HyDE → CRAG、Self-RAG、Adaptive RAG。横跨第三、四幕的最佳实操系列。
15. Self-RAG 项目页 — https://selfrag.github.io/ — 反思 token 框架图解，论文 / 代码 / 7B·13B 模型（讲义 p.57）。
16. DeepLearning.AI 短课《Building Agentic RAG with LlamaIndex》（免费，约 54 分钟 6 课，Jerry Liu）— https://www.deeplearning.ai/short-courses/building-agentic-rag-with-llamaindex/ — 路由查询引擎 → 工具调用 → agent 推理循环 → 多文档 agent。

**第五幕 · 失败动物园**
17. Barnett et al.《Seven Failure Points When Engineering a RAG System》（arXiv:2401.05856）— https://arxiv.org/abs/2401.05856 — 三个真实案例的七失败点经验报告；核心论断"RAG 的健壮性是演化出来的，不是一开始设计出来的"。
18. Liu et al.《Lost in the Middle: How Language Models Use Long Contexts》（arXiv:2307.03172，TACL 2023）— https://arxiv.org/abs/2307.03172 — U 形曲线：证据放中间就被丢——阅读侧失效的实证根源，也是 L02 context rot 的原始证据。
