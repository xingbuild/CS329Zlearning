## 1 · 材料清单（9 条正选）

**第一幕 · 工程三支柱与 Agency 光谱**
1. Karpathy《Software Is Changing (Again)》（演讲，2025-06，YC AI Startup School）— https://www.ycombinator.com/library/MW-andrej-karpathy-software-is-changing-again — Software 1.0/2.0/3.0 三范式与 **LLMOS 隐喻（LLM=CPU、context=RAM、工具=外设）**——整讲的宇宙观级开胃菜，harness/编排为什么存在的一段全景。（YouTube 版视频 ID 检索未稳定，YC Library 页内嵌视频+文字稿，以此为准。）

**第二幕 · DSPy 与 LangGraph**
2. [DSPy 官方文档](https://dspy.ai) — Stanford NLP 官方：Signatures / Modules / Optimizers（GEPA、MIPROv2、BootstrapFewShot）指南——"Program, don't prompt"的出处。课文"50 行复刻 Optimizer"的官方对照。（延伸阅读已挂此链，资源页展开定位。）
3. DeepLearning.AI《AI Agents in LangGraph》（免费短课，1h42m，Harrison Chase）— https://www.deeplearning.ai/short-courses/ai-agents-in-langgraph/ — 先**手写** agent 再用 LangGraph 重建——课程结构与"框架没发明新机制，只加语法与配套"的课文论点完全同构。
4. 《挑战 19 分钟搞定：LangGraph 快速入门与原理剖析》（中文视频，B 站）— https://www.bilibili.com/video/BV1HVFLzfEeS — 敲代码的码农，5.1 万播放，State/Node/Edge 四原语的中文速览。

**第三幕 · Agent Harness 四案例（一手 repo 实物）**
5. [mini-swe-agent](https://github.com/SWE-agent/mini-swe-agent)（GitHub，约 9k★）— 约 100 行核心、bash 唯一工具、SWE-bench Verified >74%——"极简→评测变量最少"哲学的实物。
6. [OpenHands](https://github.com/All-Hands-AI/OpenHands)（GitHub，约 92k★）— 事件溯源架构的编码 agent 平台（讲义"可回放调试"的出处）。
7. [Pi](https://github.com/badlogic/pi-mono)（GitHub，约 118.9k★）— Mario Zechner 的极简 harness；**注意 repo 已迁移至 earendil-works/pi**（badlogic 旧路径仍自动重定向），官方文档 pi.dev 已挂延伸阅读。
8. [OpenClaw](https://github.com/openclaw/openclaw)（GitHub，约 393k★）— 常驻型个人助理（Gateway + 20+ 消息通道 + 本地数据）；"跨会话人格与夜间记忆整理"的实物样本。

## 3 · 融入建议

- 页首坦诚话：本讲资源以**课程与 repo 实物**为主——选型层的学问在别人的代码与判据里，不在几何可视化里。
- 动手任务（三个，L03 模具）：
  1. **读 mini-swe-agent 的 agent 主类**（约 100 行）：找出课文复刻清单的五个零件（状态/工具表/循环壳/错误回喂/重试预算）各对应哪几行——"复刻检验"的现实版。
  2. **对照 Pi 与 OpenClaw 的工具清单**：一个 4 件套 vs 一个全都要——用"什么时候你会选它"表格自己判一遍（思考题 3 的扩展）。
  3. **Karpathy 的 LLMOS 隐喻**：把本课程八讲各映射到"CPU/RAM/外设/进程"的哪个位置——检验你是否建立了全课程的一张图。
- 登记：目录式 `site/l05/resources/index.md`；侧栏 L05 组；课文延伸阅读入口。
