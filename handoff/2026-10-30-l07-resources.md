## 1 · 材料清单（8 条正选）

**第一/二幕 · 类型学与设计三问**
1. Letta 官网 — https://www.letta.com — MemGPT 团队公司站：研究线（MemGPT、context repositories、**sleep-time compute**）与 Letta Agent 产品——"记忆是一门生意也是一条研究前沿"的全貌。

**第三幕 · 四大架构模式**
2. DeepLearning.AI《LLMs as Operating Systems: Agent Memory》（免费短课，约 1.5h）— https://www.deeplearning.ai/short-courses/llms-as-operating-systems-agent-memory/ — **MemGPT 论文作者 Charles Packer / Sarah Wooders 亲授**：自编辑记忆、两层记忆架构、core/archival blocks、agentic RAG——课文 MemGPT 费曼级的官方课程版。本讲主打。
3. [Generative Agents 官方代码库](https://github.com/joonspk-research/generative_agents)（GitHub，约 22.3k★）— 25 人小镇的完整实现（记忆流、反思、规划）。注意：项目官网 generativeagents.io 对抓取持续连接失败，**以 GitHub 为准**；repo 名是下划线版 `generative_agents`。
4. [Voyager 项目页](https://voyager.minedojo.org) — 技能库三大组件（自动课程/可执行代码技能/迭代提示+自验证）的原版图示；"102 次迭代造钻石工具"论文的官方页面。
5. [Mem0](https://github.com/mem0ai/mem0)（GitHub，约 68.1k★）— 记忆层基础设施。**重要工程注记**：README 的算法已从论文的 ADD/UPDATE/DELETE/NOOP 演进为 **single-pass ADD-only**（只增不覆盖）——"论文 → 工程"的漂移本身是教学点（讲义是 ground truth，资源页如实标注演进）。
6. [Zep Graphiti](https://github.com/getzep/graphiti)（GitHub，约 32.4k★）— **bi-temporal 时序知识图谱**（事实带有效期、失效不删除）——课文"知识图谱底座"与"多跳关联"的最新工业实现。
7. Letta《Sleep-time Compute》博文（2025-04-21）— https://www.letta.com/blog/sleep-time-compute — "learned context"概念、闲时整理的 Pareto 改进、主 agent + 后台 sleep-time agent 双体架构（MemGPT 2.0 / Letta 0.7.0）——课文"睡眠维护"模式的一手出处。

**第四/五幕 · 评估与开放问题**
8. LangChain《How we built agent memory》— https://www.langchain.com/blog/how-we-built-agent-builders-memory-system — "文件系统底座 + grep/ls 即记忆工具"的工业实录（延伸阅读已挂链，展开定位：它同时是第五幕"记忆即工程系统"的注脚）。
